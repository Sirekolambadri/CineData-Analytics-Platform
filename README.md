# CineData Analytics Platform

## An Interactive SQL-Based Movie Booking Data Analysis System

CineData Analytics Platform is an interactive web application developed using Python and Streamlit for querying and analyzing a MySQL-based movie booking database.

The application provides a simple interface where users can connect to the movie booking database, explore tables and schemas, write SQL queries, execute read-only queries, view the results, and download only the results generated by a particular query.

---

## Features

- MySQL Database Connectivity
- Interactive Streamlit Interface
- Table Explorer
- Database Schema Information
- SQL Query Editor
- Read-Only SQL Query Execution
- Query Results Display
- Query Execution Information
- Download Query Results as CSV
- Download Query Results as Excel
- SQL Error Handling
- Protection Against Destructive SQL Operations

## Database

The project uses the following MySQL database:

**Database Name:** `movies_bookig_db`

### Tables

The database contains the following tables:

- `bookings`
- `customers`
- `movies`
- `screens`
- `theatres`

The complete database structure is provided in the `movies_bookig_db.sql` file included in this repository.
